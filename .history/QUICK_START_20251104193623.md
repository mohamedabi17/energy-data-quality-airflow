## 🛠️ Cleaning Operations Applied

### 1. Unit Normalization
**Before**: `Paris consumption = 1940, 500, 2200 Wh`  
**After**: `Paris consumption = 1.94, 0.5, 2.2 kWh`  
**Logic**: `IF value > 1000 THEN value / 1000`

### 2. Address Standardization
**Before**: `Evry-Courcouronnes, 91000, 19 Boulevard Aguado`  
**After**: `Evry-Courcouronnes, 19 Boulevard Aguado`  
**Logic**: Remove postal code from address field

### 3. CSP Code Mapping
**Before**: `3, 4, 5, 6` (numeric codes)  
**After**: `Cadres et professions intellectuelles supérieures, Professions intermédiaires, Employés, Ouvriers`  
**Logic**: Map using predefined dictionary

### 4. Salary Imputation
**Before**: `Salaire_Moyen = NULL`  
**After**: `Salaire_Moyen = (Salaire_Min + Salaire_Max) / 2`  
**Example**: `Min=30000, Max=50000 → Moyen=40000`

## 🐛 Common Issues

### Issue: "File not found"
**Solution**: Ensure you're in the correct directory and CSV files exist

### Issue: "Module not found"
**Solution**: `pip install -r requirements.txt`

### Issue: "All metrics are 100% invalid"
**Solution**: This is expected on uncleaned data! Run the cleaning script.

### Issue: "Airflow DAG not found"
**Solution**: Copy dags folder to `$AIRFLOW_HOME/dags/` and restart scheduler
