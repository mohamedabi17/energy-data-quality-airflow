# Output Directory Structure

This document explains the organization of output files generated by the data quality pipeline.

## Directory Overview

```
new QD data/
├── metadata/                    # Data quality metrics
│   └── metadata_qd.csv         # 40 metrics (semicolon-separated)
│
├── cleaned_data/               # Cleaned and standardized CSV files
│   ├── Consommation_Evry_cleaned.csv
│   ├── Consommation_Paris_cleaned.csv
│   ├── Population_Evry_cleaned.csv
│   ├── Population_Paris_cleaned.csv
│   └── CSP_cleaned.csv
│
└── target_schemas/             # Aggregated target schemas
    ├── Consommation_IRIS_Paris.csv
    ├── Consommation_IRIS_Evry.csv
    └── Consommation_CSP.csv
```

## Directory Purposes

### 1. `metadata/`
**Purpose**: Store data quality metrics  
**Created by**: `compute_metrics.py`  
**Contains**:
- `metadata_qd.csv` - 40 data quality metrics with percentage of invalid values

**Format**:
```csv
pct_CP_invalid_cons_evry;pct_Nom_Rue_invalid_cons_evry;...
0.00%;8.33%;...
```

### 2. `cleaned_data/`
**Purpose**: Store cleaned and standardized versions of source files  
**Created by**: `clean_data.py`  
**Contains**: 5 cleaned CSV files with `_cleaned` suffix

**Transformations applied**:
- ✅ Wh → kWh conversion (values > 1000 divided by 1000)
- ✅ Address standardization (Paris and Evry formats)
- ✅ CSP numeric-to-text mapping (3→Cadres, 4→Professions Intermédiaires, etc.)
- ✅ Postal code cleaning (5 digits only)
- ✅ Duplicate removal
- ✅ Salary imputation for CSP table

### 3. `target_schemas/`
**Purpose**: Store aggregated target schemas with business metrics  
**Created by**: `aggregate_data.py`  
**Contains**: 3 target schema files

**Files**:

#### Consommation_IRIS_Paris.csv
- **Columns**: `ID_IRIS`, `Conso_moyenne_annuelle`
- **Rows**: 5 IRIS zones in Paris
- **Description**: Average annual consumption per IRIS geographic zone in Paris
- **Calculation**: AVG(NB_KW_Jour × 365) grouped by IRIS

#### Consommation_IRIS_Evry.csv
- **Columns**: `ID_IRIS`, `Conso_moyenne_annuelle`
- **Rows**: 6 IRIS zones in Evry-Courcouronnes
- **Description**: Average annual consumption per IRIS geographic zone in Evry
- **Calculation**: AVG(NB_KW_Jour × 365) grouped by IRIS

#### Consommation_CSP.csv
- **Columns**: `ID_CSP`, `Conso_moyenne_annuelle`, `Salaire_Moyen`
- **Rows**: 5-6 socio-professional categories
- **Description**: Average annual consumption and salary by socio-professional category
- **Calculation**: AVG(NB_KW_Jour × 365) and salary joined by CSP
- **Use case**: Analyze consumption patterns vs. income levels

## Access Patterns

### Reading Cleaned Data
```python
import pandas as pd
import os

base_path = r"c:\Users\mohamed abi\Desktop\new QD data"

# Read cleaned consumption data
cons_paris = pd.read_csv(os.path.join(base_path, 'cleaned_data', 'Consommation_Paris_cleaned.csv'))
```

### Reading Target Schemas
```python
# Read IRIS aggregation
iris_paris = pd.read_csv(os.path.join(base_path, 'target_schemas', 'Consommation_IRIS_Paris.csv'))

# Read CSP aggregation
csp = pd.read_csv(os.path.join(base_path, 'target_schemas', 'Consommation_CSP.csv'))
```

### Reading Metrics
```python
# Read metrics (semicolon-separated)
metrics = pd.read_csv(os.path.join(base_path, 'metadata', 'metadata_qd.csv'), sep=';')
```

## Directory Creation

All directories are created automatically by the scripts:

```python
# clean_data.py creates cleaned_data/
os.makedirs(os.path.join(base_path, 'cleaned_data'), exist_ok=True)

# aggregate_data.py creates target_schemas/
os.makedirs(os.path.join(base_path, 'target_schemas'), exist_ok=True)

# compute_metrics.py creates metadata/
os.makedirs(os.path.join(base_path, 'metadata'), exist_ok=True)
```

## Cleanup

To reset and regenerate all outputs:

```powershell
cd "c:\Users\mohamed abi\Desktop\new QD data"

# Remove all outputs
Remove-Item -Recurse -Force cleaned_data, target_schemas

# Re-run pipeline
cd dags\scripts
python clean_data.py
python aggregate_data.py
```

Important files to backup:

2. ✅ Scripts (dags/scripts/*.py)
3. ⚠️ `cleaned_data/` - Can be regenerated, but backup for quick recovery

5. ✅ `metadata/metadata_qd.csv` - Historical metrics for trend analysis

## Notes

- **Separation rationale**: Cleaned data and target schemas serve different purposes
  - `cleaned_data/`: Individual table cleaning, 1:1 with source files
  - `target_schemas/`: Business-level aggregations, multiple tables joined
  
- **Airflow integration**: DAG tasks write to these directories automatically

- **Disk space**: All outputs combined are < 5 KB for current dataset

- **Performance**: Directory separation improves clarity and maintainability
