# Complete Data Quality Pipeline

## Overview

This project implements a **complete data quality and ETL pipeline** using Apache Airflow with 4 sequential stages:

```
1. Compute Uncleaned Metrics → 2. Clean Data → 3. Aggregate Data → 4. Compute Cleaned Metrics
```

## Pipeline Stages

### Stage 1: Compute Uncleaned Metrics
- **Script**: `dags/scripts/compute_metrics.py`
- **Purpose**: Calculate 40 data quality metrics on raw data
- **Output**: `metadata/metadata_qd.csv` (semicolon-separated)
- **Metrics**: Postal codes, addresses, consumption ranges, CSP codes, salaries

### Stage 2: Clean Data
- **Script**: `dags/scripts/clean_data.py`
- **Purpose**: Improve data quality through standardization
- **Operations**:
  - **Unit Normalization**: Convert Wh → kWh (divide values > 1000 by 1000)
  - **Address Standardization**: Fix Paris and Evry address formats
  - **CSP Mapping**: Map numeric codes (1-6) to text descriptions
  - **Duplicate Removal**: Remove duplicate rows by primary key
  - **Salary Imputation**: Calculate missing salaries as (Min + Max) / 2
- **Output**: `cleaned_data/*_cleaned.csv` files

### Stage 3: Aggregate Data
- **Script**: `dags/scripts/aggregate_data.py`
- **Purpose**: Create target schemas with aggregated consumption data
- **Operations**:
  - Join consumption data with IRIS table (by street name)
  - Calculate average annual consumption per IRIS zone (daily * 365)
  - Join population with consumption and CSP salary data
  - Aggregate consumption by socio-professional category
- **Output**: 
  - `cleaned_data/Consommation_IRIS_Paris.csv` (ID_IRIS, Conso_moyenne_annuelle)
  - `cleaned_data/Consommation_IRIS_Evry.csv` (ID_IRIS, Conso_moyenne_annuelle)
  - `cleaned_data/Consommation_CSP.csv` (ID_CSP, Conso_moyenne_annuelle, Salaire_Moyen)

### Stage 4: Compute Cleaned Metrics (Optional)
- **Script**: `dags/scripts/compute_metrics.py`
- **Purpose**: Recalculate metrics on cleaned data to measure improvement
- **Output**: Updated `metadata/metadata_qd.csv`

## Running the Pipeline

### Option 1: Run with Airflow (Production)

```powershell

airflow webserver --port 8080

# In another terminal, start scheduler
airflow scheduler

# Access UI at http://localhost:8080
```

## Data Issues Found & Fixed

### Issue 1: Paris Consumption Unit Error
**Problem**: All consumption values > 1000 (100% invalid in `pct_invalid_kw_cons_paris_unit`)  
**Root Cause**: Values are in Wh, not kWh  
**Solution**: Cleaning script divides by 1000 to convert Wh → kWh

### Issue 2: Evry Addresses Include Postal Codes
**Problem**: 100% of addresses invalid in Population_Evry  
**Root Cause**: Postal code included in address field (e.g., `Evry-Courcouronnes, 91000, 19 Boulevard`)  
**Solution**: Cleaning script removes postal code: `Evry-Courcouronnes, 19 Boulevard Aguado`

### Issue 3: Numeric CSP Codes
**Problem**: 100% invalid CSP codes in Population_Evry  
**Root Cause**: Using numeric codes (3, 4, 5, 6) instead of text  
**Solution**: Mapping: 1→Agriculteurs, 2→Artisans, 3→Cadres, 4→Professions Intermédiaires, 5→Employés, 6→Ouvriers

### Issue 4: Null Values in Unit Validation
**Problem**: Null values incorrectly counted in percentage calculation  
**Solution**: Validation functions return `None` for nulls to exclude from denominator

## Validation Rules Summary

| Validation Type | Rule | Example |
|----------------|------|---------|
| **Postal Code** | Exactly 5 digits | `75001`, `91000` |
| **Paris Address** | `Paris, [num] rue [street]` | `Paris, 10 rue Victor Hugo` |
| **Evry Address** | `Evry-Courcouronnes, [num] [type] [street]` | `Evry-Courcouronnes, 19 Boulevard Aguado` |
| **Consumption** | Range [0, 1000] kWh/day | `150.5` ✓, `2500` ✗ |
| **Unit Check** | Must be ≤ 1000 | Values > 1000 flagged as Wh |
| **CSP** | Match 52 valid categories | Case-insensitive text match |

## Target Schema Details

### Consommation_IRIS_Paris
- **Columns**: `ID_IRIS`, `Conso_moyenne_annuelle`
- **Rows**: 5 IRIS zones in Paris
- **Calculation**: Average annual consumption = AVG(NB_KW_Jour × 365) per IRIS
- **Join**: Consumption.Nom_Rue ↔ IRIS.ID_Rue (street name matching)

### Consommation_IRIS_Evry
- **Columns**: `ID_IRIS`, `Conso_moyenne_annuelle`
- **Rows**: 6 IRIS zones in Evry-Courcouronnes
- **Calculation**: Average annual consumption per IRIS
- **Join**: Consumption.Nom_Rue ↔ IRIS.ID_Rue

### Consommation_CSP
- **Columns**: `ID_CSP`, `Conso_moyenne_annuelle`, `Salaire_Moyen`
- **Rows**: 5 socio-professional categories
- **Calculation**: Average annual consumption per CSP with salary data
- **Join**: Population.CSP ↔ CSP.Desc, Population.Adresse ↔ Consumption.Nom_Rue (street)
